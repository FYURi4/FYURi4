# FYURI4 HOME

Привет! Я системный инженер и веб‑разработчик. В работе сочетаю Linux‑инфраструктуру и современную фронтенд‑разработку.

## 🧠 О себе

- Системное программирование, Linux, автоматизация
- Веб: Laravel, Inertia.js, Vue, Tailwind
- LUA: встраиваемые скрипты, логика, интеграция
- Пишу кастомные админки, проектирую роли и права (Spatie Permissions)
- Люблю чистые архитектуры и понятную документацию
